# AI Video Generator (Streamlit Version)

### Features
- Text Prompt / Voice Upload input
- TTS (gTTS) and Whisper transcription
- AI Image generation (OpenAI DALL·E)
- Multilingual (Hindi, English, Kannada)
- NSFW-safe, dark UI, auto-cleanup
- Streamlit free online deploy support

### How to Deploy
1. Upload this folder to GitHub
2. Go to https://streamlit.io/cloud
3. Click 'Deploy App', link your GitHub repo
4. Set `app.py` as the main file
